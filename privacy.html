Privacy Policy — ReelForge

Last updated: November 5, 2026

1. No data collection

ReelForge does not include any analytics, telemetry or advertising SDKs, and does not send your personal data to any server operated by the developer. All video processing happens on your own computer.

2. Third-party services (TikTok)

When you choose to link your TikTok account, ReelForge exchanges an OAuth authorization code directly with TikTok's official API endpoints (open.tiktokapis.com). The tokens are stored only in a local file on your machine and are never transmitted anywhere else. Through the official API, only the information strictly required to publish the video you explicitly select (the video file and the caption you edited) is sent to TikTok. TikTok's own handling of that data is governed by TikTok's privacy policy.

3. Your rights

You can revoke the connection and delete all local credentials at any time: open ReelForge, click "Scollega", or delete the file data/tiktok_tokens.json. Never share those files with anyone.

4. Contact

Open an issue at the project's GitHub repository for any privacy-related question.
